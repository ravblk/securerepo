# SecureRepo 🛡️

SecureRepo Batch Auditor — корпоративная система массового аудита безопасности кодовых баз (SaaS, Private Cloud / On-Premise).

## 🏗️ Архитектура

Проект построен по микросервисной архитектуре и поддерживает два режима развертывания:

- **Docker Compose** — для локальной разработки и тестирования
- **Kubernetes** — для продакшн окружений

### Инфраструктурные сервисы

| Сервис | Назначение | Порт |
|--------|------------|------|
| **PostgreSQL** | Реляционная база данных для метаданных и результатов аудита | 5432 |
| **Qdrant** | Векторная база данных для эмбеддингов правил и кода | 6333 |
| **Kafka** | Очередь сообщений для асинхронной обработки задач | 9092 |
| **Keycloak** | Аутентификация и авторизация пользователей | 8180 |
| **Langfuse** | Мониторинг и трассировка LLM операций | 3000 |

### Core сервисы

#### Embedding Service
- Создает векторные представления кода и правил безопасности
- Модель: `BAAI/bge-m3`
- Требует до 8GB RAM для работы

### Бизнес сервисы

| Сервис | Описание | Порт |
|--------|----------|------|
| **API Service** | REST API для управления аудитами | 8000 |
| **Frontend Service** | Веб-интерфейс системы | 3000 |
| **Indexer Service** | Индексация репозиториев в векторной базе | 8002 |
| **Internal Rules Ingestion** | Импорт внутренних правил безопасности | 8001 |
| **OWASP Seeder** | Загрузка OWASP правил в систему | 8004 |
| **Audit Worker** | Анализ кода с использованием LLM | — |
