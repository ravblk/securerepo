# ADR: Выбор модели эмбеддингов — универсальная BAAI/bge-m3

## Status
Accepted

## Context

SecureRepo Batch Auditor использует RAG для поиска политик и кода. Нужна модель эмбеддингов.

Требования:
- Для текста (Confluence): поддержка русского языка
- Для кода: понимание синтаксиса, функций, зависимостей

*BAAI/bge-m3*
- Языки: 100+ включая русский
- Dimensions: 1024
- Context: 512 токенов
- Обучен на коде и естественном языке

## Decision

Выбрана **одна универсальная модель** — BAAI/bge-m3:

| Тип данных | Модель | Коллекция Qdrant |
|------------|--------|------------------|
| Текст (Confluence) | BAAI/bge-m3 | internal_policies |
| Код | BAAI/bge-m3 | code_repo |
| OWASP/CWE | BAAI/bge-m3 | general_best_practices |

Обоснование:
1. **Универсальность**: Одна модель для кода и текста — упрощает инфраструктуру
2. **Мультиязычность**: 100+ языков включая русский
3. **Обучение**: Обучен на коде и естественном языке — компромисс между специализированными моделями
4. **Размерность**: 1024 — единая для всех коллекций Qdrant
5. **Экспертиза**: Open source с хорошей документацией

## Consequences

**Pros:**
- Одна модель вместо двух — проще развёртывание
- Единая размерность (1024) — одна коллекция в Qdrant
- Поддержка русского языка для Confluence
- Достаточное качество на коде

**Cons:**
- Специализированные модели (GraphCode-BERT) могут быть лучше на коде
- Компромиссное решение vs специализация

**Mitigations:**
- TEI-сервер на одном порту (8080)
- Один эндпоинт для всех типов данных
