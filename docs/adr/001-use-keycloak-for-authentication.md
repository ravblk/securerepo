# ADR-001: Использование Keycloak для аутентификации и авторизации

**Дата:** 2026-08-31
**Статус:** Принято

## Контекст

Для системы SecureRepo Batch Auditor требуется механизм аутентификации и авторизации пользователей. Необходимо выбрать решение, которое будет работать в air-gapped окружении (без доступа к внешним облачным сервисам).

## Рассматриваемые варианты

### Вариант 1: Keycloak (выбран)
- Open Source (Apache 2.0)
- Популярность: #1 в категории Identity & Access Management
- Полная поддержка OAuth2/OIDC
- Локальное развертывание (не требует внешних сервисов)

### Вариант 2: Custom JWT implementation
- Минимальные зависимости
- Полный контроль над кодом
- Требует разработки и поддержки

### Вариант 3: Cloud Provider IAM (AWS Cognito, Azure AD)
- Полная управляемость
- Не подходит для air-gapped окружения

## Решение

Используем **Keycloak** — self-hosted решение для Identity & Access Management.

## Обоснование

### Основная причина: Популярность и Open Source

1. **Популярность:**
   - #1 Open Source IAM решение (GitHub 25k+ stars)
   - Широкое сообщество и документация
   - Большое количество интеграций

2. **Open Source:**
   - Полный исходный код (Apache 2.0)
   - Нет vendor lock-in
   - Возможность аудита кода
   - Локальное развертывание без лицензионных платежей

3. **Соответствие требованиям:**
   - Air-gapped: работает полностью локально
   - OAuth2/OIDC: стандартные протоколы
   - RBAC: встроенная поддержка ролей
   - Docker: готовые образы для Kubernetes

### Почему не свой JWT:

| Критерий | Keycloak | Custom JWT |
|----------|----------|------------|
| Время настройки | 1 день | 1 неделя |
| Безопасность | Проверена | Требует аудита |
| OAuth2/OIDC | Из коробки | Писать с нуля |
| RBAC | Встроено | Писать с нуля |
| Поддержка | Сообщество | Собственная |

## Последствия

### Положительные:
- Быстрая интеграция с существующими системами
- Готовая документация и примеры
- Стандартные протоколы (OIDC)
- Масштабируемость

### Отрицательные:
- Дополнительный компонент в архитектуре
- Требует настройки и управления

## Альтернативы в будущем

- Dex (minimal OIDC)
- ORY Hydra (OAuth2 server)
- Custom solution (если Keycloak избыточен)
